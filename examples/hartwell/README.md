# The Hartwell family

A made-up family used to try cronicl out, to take the README screenshots and to build the
[live demo](https://cbenning.github.io/cronicl/). Every person, place and event is invented, and the portraits are
generated silhouettes.

```bash
cd examples/hartwell
cronicl check
cronicl            # the terminal editor
cronicl serve      # http://127.0.0.1:8000/
```
